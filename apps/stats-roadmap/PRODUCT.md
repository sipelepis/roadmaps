# Product: Statistics Roadmap

<!-- impeccable:product-schema 1 -->

App-specific record for `apps/stats-roadmap`. Users, positioning, principles, brand voice, and constraints are shared with the other roadmaps and live in the root `PRODUCT.md`. This file holds only what differs.

## Platform

web

## Users

Same as root, applied to statistics: a developer who can already write basic Python and wants to reason about data, samples and uncertainty before reaching for a library. The articles assume comfort with lists, loops and functions, and build the statistics from seeded random numbers.

## Product Purpose

Teach statistics and probability in dependency order, from counting samples to deciding whether a change in an A/B test, a drift alert or an eval score is real, with every step runnable in the browser.

## Operating Context

- 20 modules, each with a playground, 76 exercises. Stages in graph order: Foundations, Probability and data, From samples to estimates, Inference, In production.
- Module labels in graph order: Thinking in samples, Describing data, Probability rules, Conditional probability & Bayes, Random variables, Outliers & data quality, Common distributions, Correlation & causation, Large numbers & the CLT, Sampling & bias, Least squares, Likelihood & estimation, Counting at scale, Confidence intervals & bootstrap, Entropy, cross-entropy & KL, Bayesian updating, Hypothesis tests, A/B tests, Drift detection, Error bars on evals.
- Runtime: Pyodide with the CPython standard library only. No numpy, scipy or pandas. The first Run in a session shows "Loading Python…".
- All data is synthetic and generated by code shown in the article, so each estimate can be compared with a known truth.
- A Reference page (`#/reference`) lists the standard library calls, notation and formulas the modules use. It is a lookup page, not a graph node.
- Not yet deployed. The Vercel project `stats-roadmap` is still to be created from `apps/stats-roadmap`.

## Capabilities and Constraints

- Exercises must run offline with the standard library only. Randomness comes from a seeded `random.Random` passed in by the caller, so tests can pin exact values.
- Brand mark: white "STAT" on magenta (#be185d). The only colour that differs from the other roadmaps.

## Evidence on Hand

- 20 articles under `src/content/`, each with starter and test blocks, checked by `npm run verify`. Reference solutions are checked separately, with `--solutions`.
